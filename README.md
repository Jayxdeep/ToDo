# ToDo

Its just a simple todo list based on cohort 2.0 course

# Tech Stack
- Backend: Node.js,Express.js
- Frontend: Html,Css,Js

## Run Locally

Clone the project

```bash
  git clone https://github.com/Jayxdeep/ToDo.git
```

Go to the project directory

```bash
  cd Todo
```

Install dependencies
- Frontend
```bash
  cd frontend  
  npm install
```
- backend
```bash
  cd backend  
  npm install
```

Config
- create a .env file in backend directory

```bash
  PORT=3000
```
